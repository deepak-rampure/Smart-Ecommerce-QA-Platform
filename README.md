# Smart-Ecommerce-QA-Platform

## Project Description

Smart-Ecommerce-QA-Platform is a web-based e-commerce application created for software testing and quality assurance practice.

The project covers manual testing, UI automation testing, API testing, backend validation, database testing, and defect reporting.

## Objective

The main objective of this project is to build and test an e-commerce application while applying real-world QA practices.

The project focuses on:

* Functional testing
* Manual test case design
* Selenium UI automation
* API testing using Postman
* Database validation using MySQL
* Defect identification and reporting
* Test execution and reporting
